# 彩条提取工作台 0.2

这是本轮独立实现的本地 Windows 工具。没有复用 `FS彩条提取工具`、`FS导出逆向` 或其他既有工具的实现。运行时直接读取 FS 中的原始曲线，不依赖 Flexi 安装或鼠标自动点选。

## 运行

双击 `release/彩条提取工作台/彩条提取工作台.exe`。保留该程序旁的 `_internal` 文件夹。源码方式为 `python app.py`；依赖是 Pillow、PyMuPDF、olefile。

1. 添加 FS 文件或文件夹，选择输出目录。
2. 参考库默认包含本次用户提供的 8 组 SVG，也自动查找 FS 同目录的 `导出彩条参考`。可以在界面选择额外的参考目录。
3. 点击开始批量提取。完整参考组合匹配后，从 FS 自身取出对应路径并导出；未完整匹配时，默认结果留空并提示复核，候选组合仍可切换查看。
4. 对照原图，按 ID 补选或排除对象，保存修正。列表有分页，所有选择跨页保留。
5. “打开输出目录”打开当前版本；SVG、透明 PNG 和 report.json 在该目录中。强制重跑、修正另建版本，不覆盖旧成果。

## 本次修正

- 原解析逻辑把直线节点上的历史控制柄误当有效曲线。改为依据目标节点 flag bit0 判断直线或贝塞尔；7 份新样本中涉及 1274 条路径、2661 个直线段。
- 不再把“同色、宽长、相邻”直接当作彩条。参考辅助匹配要求完整路径形状及整组相对布局成立，可包含白色、浅灰、鸟形、黑色小元素及跨组装饰。
- 参考图只用于匹配和验收，导出几何仍来自 FS。匹配不依赖固定文件名或对象编号，并支持整体平移、轴向缩放和镜像的相同图形组合；这不是对全新设计的通用视觉识别。
- 验证到的多子路径 AComposite 在保持原始 FS 叶路径的前提下重组，不用复制参考路径。
- 修复缓存索引、成果校验和修正导出事务，PNG 生成失败时保留旧版本。

## 已验证的范围

`validation/reference_exports/acceptance.json` 记录 8 组真实导出与参考的比较。统一渲染画布后，8 组均为零像素差异；源文件摘要保持不变。`reference_comparison.png` 是左右对照图。

这些例子已进入参考库，属于样例验收，不能作为未见素材准确率。现有 13 份 FS 均可解码；其中有参考的 8 份匹配完整，其余 5 份不自动认定成功。

## 接入视觉 AI

界面“AI 配置”支持带图片输入和 JSON 输出的 OpenAI 兼容 Chat Completions 接口。填写 API 根地址（如服务方提供的含 `/v1` 地址）、视觉模型名、密钥环境变量名，并启用。

默认密钥变量为 `LIVERY_API_KEY`。在本机设置环境变量后重启工具；不要把密钥放进截图、报告或共享代码。配置文件位于 EXE 旁的 `settings.json`，源码运行时位于本目录；该文件被 Git 忽略。

完整参考匹配优先使用本地确定性结果，不发起 AI 请求。没有完整参考且用户启用 AI 时，发送源文件内嵌预览、带编号的候选图和有界对象属性。AI 只能返回已给出的对象 ID，不能重画曲线。接口错误、未知 ID 或截断响应都明确拒绝，保持待复核。

目前尚未接到用户真实接口配置，仅通过离线协议测试；不能声称真实服务已联调成功。大图候选受数量上限约束，未覆盖全部对象时报告会记录遗漏数量。

## 当前限制

- 仅第 1 页，隐藏状态、完整矩阵语义、裁剪、复杂布尔操作尚未全面还原。
- 专色、CMYK、渐变及继承画刷未完整转换。未知原色会明确标记；手动选入时使用灰色诊断色，不能当作原色成品。
- SVG 为源曲线坐标及查看用像素尺寸，物理比例未验证，不能直接据此确定下料尺寸。
- 内嵌预览分辨率来自 FS，部分文件预览较小，不能凭放大增加细节。

