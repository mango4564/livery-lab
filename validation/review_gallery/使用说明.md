# 五类图案复核与成品导出

在工作台选中一份提取任务，点击“**五类图案复核 / 导出成品**”。如果是以前的任务，点击工具栏“载入已提取任务”，选择该任务的 `manifest.json`。无需重新调用 AI；旧五类任务会在本地补充可比较的组合候选。

1. 左侧按 **车身、彩条、文字、logo、徽章** 切换类别。“徽章”对应原有的门徽类别。
2. 中间显示该类候选缩略图，右侧可缩放、拖动、大窗口查看 SVG。每页 6 套图案，可翻页比较。候选分组和类别提示仍需人工判断；需要其他图案时勾选“显示全部组合（手动归类）”。
3. 点击“**确认此图为本类最佳**”，或双击候选。每类选择一套图案，切换浏览不会覆盖已确认选择。确实没有该类图案时，点击“该类没有图案（确认不导出）”。
4. 如需精细增减对象，可返回工作台，在对应类别补选、排除对象。重新打开复核页后，“当前人工补选结果”会作为一个可选图案，不需要先覆盖其他候选。
5. 五类都确认后，点击“**导出五类已确认成品**”。所有非空类别分别生成 SVG 和透明 PNG；明确无图案的类别只记录状态，不产生空图文件。

默认保存结构如下（目录及文件使用完整 FS 文件名主体，不含 `.fs` 扩展名）：

```text
输出目录/
  已复核成品/
    乾途单挡3.6米车高（车长11.7）3261754/
      车身_乾途单挡3.6米车高（车长11.7）3261754.svg
      车身_乾途单挡3.6米车高（车长11.7）3261754.png
      彩条_乾途单挡3.6米车高（车长11.7）3261754.svg
      彩条_乾途单挡3.6米车高（车长11.7）3261754.png
      文字_乾途单挡3.6米车高（车长11.7）3261754.svg
      文字_乾途单挡3.6米车高（车长11.7）3261754.png
      logo_乾途单挡3.6米车高（车长11.7）3261754.svg
      logo_乾途单挡3.6米车高（车长11.7）3261754.png
      徽章_乾途单挡3.6米车高（车长11.7）3261754.svg
      徽章_乾途单挡3.6米车高（车长11.7）3261754.png
      复核记录.json
```

也可在复核页单独更改成品保存位置。过程候选、编号图、缓存和带时间戳的运行目录不会混入该成品目录。

`复核记录.json` 保存每类是否确认、所选源对象 ID、源文件摘要及文件摘要。SVG 内也包含源摘要及类别关联。物理下料尺寸仍需独立核对。

对同一 FS 再次导出时，先完整生成新文件，再替换成品目录；旧成品自动保存在成品保存位置的 `.review_history/FS文件名/时间戳/`。渲染失败会保留原成品，取消导出不生成半套结果。同名但来自不同路径的 FS 不会合并到同一个目录；界面会要求改用其他成品保存位置。

重新打开同一任务的复核页时，会恢复默认成品位置中匹配源文件的上次确认选择，也会把这些图案加入对应类别以便再次比较。关闭页面前尚未导出的新选择不保存，以上次成功导出的复核记录为准。
