# 七组新增参考：独立源几何标注审计

本目录仅用于验收/训练标注，不由提取器加载路径。运行：

`python livery-lab/validation/reference_audit/audit_references.py --flag-only`

脚本每次从原 FS 重新解析几何，核验源与旧 manifest 摘要，遍历全部曲线按命令/数值搜索，不依据参考 metadata 中的 ID 确定匹配。命令判断候选仅在本进程替换函数，未改 core。

## 关键解析修正证据

当前基线 `path_from_nodes` 使用 `if b[0] & 1 or aox or aoy or bix or biy:`，将标记为直线但保留历史非零控制柄的节点错误解释成曲线。

本目录候选解码仅采用 **`if b[0] & 1:`** 判定进入该节点的线段类型。七份 FS 中共1274条路径、2661段存在这种历史控制柄；原始样本另有176条路径、349段。候选解码使七组32条标注路径及原样本三条全部严格0误差匹配，因此错误不只是识别筛选造成。

`baseline_current_core.json` 保留原条件下未匹配情况；`reference_vs_previous.png` 为七组参考与旧结果小图对照（灰底显示白色图形）。
