## 问题与处理

- 已分类车漆允许每个坐标轴最多为区域尺寸 0.2% 的边界偏差。多区域同时匹配时仍不指定归属，普通未分类对象沿用原容差。
- 未匹配区域的车漆按源路径包围框的空间连通性拆分；相隔的漆面不共用一个未知区域分组。该步骤不推测方向，不修改曲线。
- 复核候选、手动添加和导出采用同一规则；旧识别数据重新打开即可应用，无需重发 AI 请求。
