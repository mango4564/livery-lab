# 复核导出细线渲染一致性修复

日期：2026-10-22。分支：10.23客户演示分支，基于 2da9ac9 的未提交工作区。

## 问题与修复

整车底图的语义图层和源序 use 引用会让原有 VectorImage 离开细线原生绘制通道。
缩放矩阵下的原生 hairline 因而使用不同笔宽，导致源图与底图比较失败并抛出
`layer_order_conflict`。增加对导出语义属性及直接路径引用的支持，保持细线绘制一致。
未关闭逐像素校验；真正改变绘制顺序的图层仍被拒绝，或经过原序引用验证后导出。
一般样式、复杂引用及循环引用仍保留原 SVG 导入器处理。
