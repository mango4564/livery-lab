## 变更

- 原稿解析、多页 SVG 构建、预览图片读取、原稿定位缩略图计算移到单个后台线程。Tk 控件与 PhotoImage 仍在主线程更新。
- 只保留最新待加载请求；过期完成事件不能覆盖当前任务。最近 3 份文档的原稿与定位缩略图采用有界缓存。
- 连续缩放、拖动和尺寸变化合并到 16 ms 的重绘调度；隐藏预览页不渲染，相同视口不重复渲染。
- 同一任务重复选择不重新加载；后台事件处理每轮设置约 12 ms 预算，队列积压时短间隔继续。
