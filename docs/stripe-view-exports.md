# 彩条按原稿视图分开导出

彩条分类回答“哪些源路径属于彩条”；导出再按原稿区域划分，每个视图各输出 SVG / PNG。同一方向的不同位置也保持为不同区域，不按方向名称直接合并。

Qwen 分批可能同时选中整车车身和它的结构父组，产生重叠区域。程序现在统一整理这些重复锚点：边界近似一致且共享源路径，或边界完全重合，方向没有明确冲突时，合成一个区域。具体方向优先于“整体视图”等泛化方向。不同明确方向仍保持歧义，不靠坐标猜测左右。

六类复核页面和正式成品导出共用这套区域规则，旧任务打开复核时也会整理重复区域。仍无法归属的彩条按源路径包围框是否相接拆分，标为“待确认视图”，避免不同位置的未知彩条集中导出；相离的装饰碎片可能因此成为多个待确认项。程序不重新绘图、不移动坐标，也不因此纠正分类结果。

新提取任务和保存修正会额外生成 `stripe_views/01.svg`、`01.png` 等逐区域候选图。`stripe_patterns` 记录各文件对应的源路径、区域名和方向，文件加入版本完整性校验。六类总览及 `result.svg/png` 仍用于整体核查；正式成品通过“六类图案复核与成品导出”发布，使用区域名称命名。旧版直接调用 `export_reviewed(..., patterns=None)` 保留旧文件名和整类输出兼容行为。
